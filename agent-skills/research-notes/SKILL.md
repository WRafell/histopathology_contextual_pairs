# Research notes

Use this skill when the user asks to document research findings, experiments,
validation results, or implementation decisions in this repository.

Write notes to `docs/research-notes/YYYY-MM-DD.md` using the current date.
Create the directory and file when absent; append to the existing file when it
already exists. Preserve all existing content.

Keep entries concise and evidence-based. Record the question or result, the
relevant configuration or method, concrete evidence such as paths, job IDs,
metrics, or commands, and any limitations or follow-up needed. Do not invent
results or rewrite historical entries.
